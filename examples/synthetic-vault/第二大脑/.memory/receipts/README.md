# 回执目录

每个请求处理后，这里会出现一个 `<请求 id>.md` 回执。四种 `status`：

| status | 含义 | 你的内容进库了吗 |
| --- | --- | --- |
| `completed` | 提交成功，回执带 revision 与落地证据（内容哈希或删除标记） | 是 |
| `conflict` | 提交时目标内容与期望值不一致（多半是人工编辑过） | **没有**，你的编辑完好 |
| `failed` | 提交者明确报告失败原因（校验不过、范围不允许等） | 不是 |
| `expired` | 超过存活期（默认 7 天）仍未被处理 | 不是，请求**留在盘上**等人工判断 |

`expired` 和 `failed` 的请求**不会**被自动重试，也不会被自动删除——
本产品宁可让你看到一条没处理的请求，也不悄悄替你重做决定。

回执是流水，不是记忆。删掉历史回执不影响已经写入的记忆。
