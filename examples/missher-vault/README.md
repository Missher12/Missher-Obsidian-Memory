# Missher 中文分类示例库

这是一份完全合成的目录示例。可以复制到新的独立目录作为 Obsidian Vault，再安装本仓库生成的插件三件套。

在插件设置中将根设为“记忆库”、分类设为“Missher 中文分类”、位置设为“Vault 现有分类文件夹”，预览并应用后重载。`plugin-settings.example.json` 仅说明配置结构，不需要覆盖已有 data.json。

打开“🏠 主页”，可浏览 14 类目录与教训模板。说明页属于普通笔记，不会自动进入记忆检索。

通过快速记住输入“青岚项目发布前必须检查来源版本”，标题“发布前检查”、分类“工作流”。它会成为 `工作流/发布前检查.md`；勾选待确认则先保持 pending，审核后才进入默认检索。再次建立同名不同内容会用序号后缀，原说明或笔记保持原样。

CLI / MCP 的布局启动配置必须与插件一致，详见仓库 `docs/CLASSIFICATION.md`。外部写入只排队，插件提交后回执才会成为 completed。
