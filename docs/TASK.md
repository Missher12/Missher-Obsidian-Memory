## 目标

完成一个可实际安装使用的独立 Obsidian 记忆插件。个人事实、偏好、人物、项目、知识以 Markdown 为权威；能管理、查询、更新、遗忘；明确记住直接保存，普通 AI 提取待确认；支持任务结束/闲置/周期复盘，定位漏记、记错、冲突、过期和检索失败并给出可执行修正；不需要安装 MSE。允许可选 MSE 候选联动，但不得让主体依赖它。

通用设计整理于本仓 `docs/ARCHITECTURE.md`，研究来源应链接官方资料的固定版本，不在发布文档留下用户本机绝对路径。参考 TencentDB Agent Memory 与 OpenViking 的机制，不复制两个整套后端。既有 DSH Memory 和 NAS Vault Bridge 是独立项目，不修改它们。

## 必须完成的首版使用闭环

1. 安装后能在 Obsidian 内打开记忆工作台/侧栏。包含快速记住、待确认、记忆列表、搜索与来源详情、复盘问题和设置；选择文字可保存。中文界面，键盘可用，窄窗/长文/空态/错误态/暗亮主题可靠。
2. 文件位于用户指定的库内专用根目录（缺省如 Second Brain），其他笔记不自动扫描。稳定 ID、类型、范围、状态、来源、有效期、版本和变更历史。pending 不参与已确认事实查询；同名不同实体不自动合并；无答案可明确返回空。已有手动编辑能反映到索引和结果。
3. 搜索支持中文、关键词、标签/范围、相关片段及来源跳转。索引是可重建派生物；支持基于检索片段的问答，带来源、不凭空补齐。基础记录与查询无需模型、网络、MSE 或外部服务。
4. 可配置 AI 提供方（OpenAI-compatible 接口即可，模型与地址由用户配置，不硬编码用户凭据），负责选定内容提取、复盘和带来源问答。密钥不进 Markdown/导出/日志/示例/包；能用平台密钥存储则使用，不能安全持久化时提供仅本次运行的凭据输入。没有模型时核心照常使用，AI 按钮准确说明需要配置。
5. 新增内容和会话提交进入有界持久作业；结束事件/显式“整理本次”入口、闲置检查点、每日/每周维护可设置。与纯 Obsidian 生命周期一致：应用关闭不假装常驻，下次启动只补未处理区间。可取消/暂停，未知付费请求不自动重放，不把任务 accepted 当 completed。
6. 复盘对照用户允许的原始片段与记忆，提出新增/修正/冲突/过期建议；显示证据、前后差异、接受/忽略。明确用户纠错可立即生效，AI 语义修改待审。工作台能说明某条记忆未被返回的原因。不得自动改插件源代码或发布。
7. 独立 AI 接入口：提供可实际运行的本地 CLI 和 MCP stdio，共用核心，完成 remember/propose/search/update/forget/session-commit 等必要功能。外部接口限定 Vault/root 与路径，不提供任意文件访问。最终首版契约已收敛为：外部查询只读，写入持久排队，由 Obsidian 插件作为唯一 Markdown 提交者；返回持久回执，明确 accepted/completed/conflict。Obsidian 关闭时可读且可排队，重新打开后处理，不能把排队叫作已保存。无需提供离线直接写模式，不能为支持它引入复杂文件交换来冒充任意第三方编辑下的原子 CAS。提供准确的 DSH Cordis 配置、通用 MCP 配置和真实合成端到端验证。连接入口不可强制依赖 DSH 或 MSE。
8. MSE 可选：至少可生成真实兼容 mse-method-v1 的方法候选包，展示未发送/候选/评审或验证的真实状态；没有可靠撤回/使用前检查联动时，不自动启用生产召回。关闭/缺失 MSE 的完整流程必须通过。候选导入与回执接口可选适配，不复制 MSE 实现或绕过其库。
9. 删除/停止使用能使检索、摘要和缓存失效。删除标记不含原内容，防止旧来源重复提取复活。保留历史与永久删除须明确区分。源撤回后可选 MSE 项标记未完成撤回，不伪装全部忘记。

## 关键实现约束

- 自主拆阶段并持续交付，不为缺少真实私人资料而阻塞：使用合成 Vault 和设置入口。
- 原生插件写入用 Vault.process(file, callback)，callback 必须同步返回 string。模型处理发生在它之前；callback 内核对 captured 原文/内容哈希和 revision，冲突终止。
- 人工修改不会同步改 YAML revision，必须由内容变化检测与提交前字节核对保护；pending 手改正文不自动确认。
- 跨进程 Node CLI 与 Obsidian 内写入的统一提交/互斥方案需真实测试；若无法可靠协同，外部写入走本地受控提交队列并由插件提交，文档明确运行依赖，不谎称双写安全。
- 默认库范围/项目范围先于召回，拒绝 ..、绝对路径越界、符号链接/附件夹逃逸；本地服务若采用 HTTP 必须 loopback、认证，默认不对外网开放。
- 绝不能把工具输出、AI 总结、MSE 回流、重复来源视为用户新的确认；事件 ID/来源区间/版本幂等。
- OpenAI-compatible 使用 Obsidian requestUrl 时公开 API 无 AbortSignal/stream。超时或取消必须阻止迟到提交，不声称已中止计费；真实 abort 能力单独验收。
- 内置有界调用与 token/次数配置，后台无新增证据不请求模型。读取状态不触发模型请求；保留用户模型选择，不自动换便宜/更强模型。
- 错误要在 UI 可解释，不静默丢弃或清空坏数据；部分成功逐项显示失败。
