# 0.1.0 基础运行验收与 0.1.1 修复补验

2026-10-09，macOS / Obsidian 1.14.4（installer 1.13.4）。基础闭环使用既有 0.1.0 正式三件套；后续自动复盘修复使用 0.1.1，见文末。用户指定新库中的独立合成目录为唯一业务验收范围；每次官方 CLI 操作前校验登记 ID 和精确库路径。原始日志、合成记录、截图及机器信息仅保存在本机，不随此报告发布。

## 已验证

- 工作台表单明确记住保存 confirmed；已有记录及版本从真实插件回读，搜索结果打开到对应笔记。
- 新候选提交后为 pending，默认查询按状态排除该 ID；工作台「确认」后变为 confirmed、revision 从 1 到 2，并进入召回。
- 冻结分发 CLI 的 remember 先返回 accepted/queued；实际插件处理隐藏 `.memory` 请求目录，生成 completed 回执，包含 memoryId、revision、contentHash 与真实 Markdown 路径。
- 冻结分发 MCP stdio 完成初始化、工具发现、memory_remember 排队；实际插件提交后 memory_wait_receipt 返回 completed，memory_search 以正确 text 参数检索到合成记录。
- 通过公开 Vault.modify 修改合成正文，保持 YAML revision 不变。真实事件触发索引刷新，未手动 load/rebuild 即可查到新词。随后携带旧 hash/revision 的 CLI update 返回 conflict，编辑后的新正文保留。
- 通过合成过期复查日期触发本地确定性建议，工作台可展示证据与「忽略」处理。未连接模型、未生成假模型输出。
- 外部 forget 经插件提交后变为 archived，并退出默认查询。
- 空内容提交保留表单并显示准确提示；长文本草稿经程序化 Escape 键事件取消，未落盘。
- 对实际工作台临时施加 300 × 420 CSS 像素布局，并分别切换深浅主题类，横向 scrollWidth 等于 clientWidth（300）；长请求路径换行、内容可纵向滚动。已查看官方截图，原样式与主题已恢复。这是受控面板布局检查，不是整窗物理缩放。
- 最后 `dev:errors` 为 No errors captured。CLI/MCP 队列无 pending/claimed 请求；AI/MSE 始终关闭。

## 限制

物理键鼠、长时间自动调度、退出后恢复、Windows/macOS 之外的原生桌面、真实远端模型计费/取消、实际 MSE 接收和多设备并发未由本轮验收覆盖。相关离线测试保留其原有证据层，不能替代上述实测。程序化 DOM 调用或事件不标为物理点击。

本轮有几处验收驱动参数校正：CLI 布尔选项移到参数尾部、conflict 的非零退出码按预期结果读取、候选隔离断言按目标 ID 检查（中文分词可能命中其他 confirmed 记录）、MCP 检索使用 schema 的 text 字段。原始失败记录保留，校正后检查通过；这些没有修改产品运行代码。

## 0.1.1 自动复盘修复与补验

收尾核对发现自动复盘开关未被调度入口读取，本地维护也未执行确定性复盘，并且误走模型预算预占。0.1.1 在现有插件内修复：

- 自动调度读取 autoReview、暂停和卸载状态，防止并行 tick 重复派发；手动复盘仍可用。
- 写入/实际文件刷新记录活动时间，闲置检查点可触发本地复盘；相同输入不重复创建闲置本地检查。
- 维护作业实际运行本地复盘、报告建议数；存储读取失败记录失败，不伪装完成。
- 本地维护不申请模型预算、不标记计费，不因模型额度不足而停摆；既有模型作业闸门保留。
- 设置文案明确会话提交先入库，随后进入闲置/周期检查点，不承诺后台常驻或立即完成会话复盘。

本机 232 项测试与 18/18 自检通过（含 CLI 34 / MCP 88 项）；新增 4 项针对性测试覆盖关闭/暂停、额度耗尽、重复 tick、闲置与读取失败。实际新库在备份、停用插件、替换三件套、启用及官方 plugin:reload 后补验：

- 实际版本 0.1.1。enable 后短暂显示旧 manifest 缓存，官方 reload 后重新发现正确版本。
- 仅在合成测试根将运行间隔临时缩短并把模型 token 额度设到不足一次请求；autoReview=false 时无新增作业。
- autoReview=true 时两个同时发起的 tick 只产生一个 completed 维护作业，实际发现 2 条本地建议，billableRequestSent=false，预算字节值保持。
- 新版 CLI→真实插件 completed 与人工编辑事件复验；`dev:errors` 无错误。完整基础闭环的 0.1.0 证据与 0.1.1 本轮补验分开保留。
- 结束后所有临时配置已恢复：实际根 Second Brain、自动复盘开启、10 分钟/24 小时/168 小时默认触发、AI/MSE 关闭、插件保持启用。用户原笔记哈希保持；验收目录与备份保留。
